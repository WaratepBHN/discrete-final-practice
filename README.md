# Discrete / 20

แบบฝึกภาษาไทย 20 ข้อ สำหรับทบทวน Discrete Mathematics: Number Theory (4), Relations (6), Graphs (10) เป็นโจทย์แต่งใหม่เพื่อต่อยอดจากหัวข้อการบ้าน ไม่ใช่ข้อสอบจริงหรือเอกสารทางการของรายวิชา

- เลือกคำตอบถูกเพียงข้อเดียว ตรวจแล้วแสดงเหตุผลของคำตอบที่เลือก พร้อมวิธีทำและเหตุผลของทุกตัวเลือก
- สลับตำแหน่งตัวเลือกแต่ละรอบ ล็อกคำตอบแรกหลังตรวจ แสดงคะแนนและรายการข้อที่ควรทวน
- บันทึกความคืบหน้าใน localStorage ของเบราว์เซอร์นั้น ไม่มีบัญชีผู้ใช้หรือระบบเก็บคำตอบบนเซิร์ฟเวอร์
- ใช้ได้บนโทรศัพท์ มีรูปกราฟ SVG ตาราง และเมทริกซ์
- เมื่อโหลดเว็บครบครั้งแรกแล้ว รองรับการกลับมาใช้ออฟไลน์ผ่าน service worker ในเบราว์เซอร์ที่รองรับ

## เปิดในเครื่อง

ใช้ static HTTP server เช่น `python -m http.server 8787` จากโฟลเดอร์นี้ แล้วเปิด `http://localhost:8787` (อย่าเปิด index.html ด้วย file:// เพราะมีการโหลด JSON)

## GitHub Pages

Settings → Pages → Deploy from a branch → main → /(root) → Save

ไฟล์ที่ต้องเผยแพร่: index.html, styles.css, app.js, questions.json, sw.js, icon.svg และ .nojekyll เท่านั้น ไม่ต้องมีขั้นตอน build หรือ dependency ภายนอก

## Convention ในโจทย์

ใช้ข้อกำหนดรายวิชาที่ระบุในโจทย์ เช่น simple path ไม่ซ้ำ edge, Euler circuit นับเป็น Euler path แบบปิด, Wₙ เริ่มจาก Cₙ แล้วเพิ่ม hub และการหารลงตัวใช้ตัวหารที่ไม่เป็นศูนย์

เฉลยอยู่ใน questions.json ตามธรรมชาติของเว็บฝึกฝนฝั่งเบราว์เซอร์ จึงไม่ได้ออกแบบเพื่อใช้เป็นระบบสอบควบคุม
